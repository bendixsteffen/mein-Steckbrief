Ich bin Bendix – technisch geprägt, hands-on unterwegs und auf meinem Weg in die IT. Mein Schwerpunkt liegt auf **Linux-Systemadministration, Netzwerken, Automatisierung und Cloud-Grundlagen**.

Aus meiner mehrjährigen Berufspraxis in Metallbau, Fahrzeugfertigung und Sicherheitstechnik bringe ich etwas mit, das auch im IT-Alltag zählt: strukturiertes Vorgehen, Qualitätsbewusstsein, technisches Verständnis und einen klaren Blick für funktionierende Lösungen.
